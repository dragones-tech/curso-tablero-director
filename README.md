# El tablero del director con IA (6 horas)

Materiales del curso. Si eres participante, **empieza por la instalación** antes del día del curso.

## Contenido de la carpeta

```
cursoSEDU/
├── plan/          Temario (PDF) y presentación paso a paso (HTML)
├── instalacion/   Guía y programas para preparar tu computadora
│   ├── README.md    ← guía paso a paso
│   ├── windows/     scripts de instalación para Windows
│   ├── mac/         (pendiente)
│   └── proyecto/    proyecto base (CLAUDE.md, plan, app) que se copia a tu computadora
├── alumnos/       Archivos de ejemplo para las prácticas
└── instructor/    Solo para el instructor (no se publica en el repositorio)
```

| Carpeta | Para quién | Qué contiene |
|---|---|---|
| [`plan/`](plan/) | Todos | El temario del curso (PDF) y la presentación `curso-paso-a-paso.html` (se abre en el navegador). |
| [`instalacion/`](instalacion/README.md) | Participantes | La [guía de instalación](instalacion/README.md) y los programas que la hacen. |
| [`alumnos/`](alumnos/) | Participantes | Archivos de la *Organización Ejemplo* (ficticia) para las prácticas. Lee primero `LEEME.txt`. |
| `instructor/` | Instructor | Clave de resultados. No está en el repositorio público; solo en la copia del instructor. **No incluir** al repartir los materiales. |

## Pasos para participantes

1. **Antes del curso:** sigue la [guía de instalación](instalacion/README.md).
2. **El día del curso:** abre Ubuntu, `cd ~/proyecto-python` y `claude`. La instalación ya copió ahí los archivos de `alumnos/` (en `archivos_ejemplo/`).
